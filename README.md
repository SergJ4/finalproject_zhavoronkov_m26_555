# Valutatrade Hub

Valutatrade Hub — CLI-приложение для управления валютным портфелем пользователя. Поддерживает регистрацию и аутентификацию, покупку/продажу валюты, конвертацию по актуальным курсам, а также автоматическое обновление курсов из внешних API (CoinGecko, ExchangeRate-API).

## Структура проекта

```
├── valutatrade_hub/
│   ├── cli/              # Интерфейс командной строки (оркестрация)
│   ├── core/             # Бизнес-логика (модели, usecases, утилиты)
│   ├── infra/            # Инфраструктура (БД, настройки)
│   └── parser_service/   # Парсер внешних API курсов валют
├── data/                 # Базы данных (users.json, portfolios.json, rates.json)
├── logs/                 # Логи (actions.log, parser.log)
├── config.json           # Конфигурация приложения
├── main.py               # Точка входа
└── pyproject.toml        # Зависимости и метаданные
```

## Установка

Проект использует [uv](https://github.com/astral-sh/uv) для управления зависимостями.

```bash
# Установка зависимостей
uv sync
```

Если uv не установлен:
```bash
pip install uv
uv sync
```

## Запуск

```bash
uv run python main.py
```

После запуска введите команду (например, `register`, `login`, `exit`). Введите `help` для списка доступных команд.

# Parser Service — обновление курсов валют

Parser Service загружает актуальные курсы валют из внешних API и сохраняет их в локальный кэш.

## Команды

### update-rates

Загружает курсы из всех доступных источников (или из указанного).

**Команда**: `update-rates [--source coingecko|exchangerate]`

**Примеры**:
```bash
# Обновить из всех источников
update-rates

# Обновить только из CoinGecko
update-rates --source coingecko

# Обновить только из ExchangeRate-API
update-rates --source exchangerate
```

**Пример вывода**:
```
INFO: Starting rates update...
INFO: Fetching from CoinGecko... OK (3 rates) [1.23s]
INFO: Fetching from ExchangeRate-API... OK (3 rates) [0.87s]
Update successful. Total rates updated: 6.
```

При ошибке одного из источников:
```
ERROR: Failed to fetch from CoinGecko: Network error.
INFO: Fetching from ExchangeRate-API... OK (3 rates)
Update completed with errors. Check logs/parser.log for details.
```

### show-rates

Показывает текущие курсы из локального кэша.

**Команда**: `show-rates [--currency <str>] [--top <int>] [--base <str>]`

**Параметры**:
| Параметр | Описание |
|----------|----------|
| `--currency <str>` | Показать курс только для указанной валюты |
| `--top <int>` | Показать N самых дорогих курсов |
| `--base <str>` | Показать все курсы относительно указанной базы |

**Примеры**:
```bash
# Все курсы
show-rates

# Только BTC
show-rates --currency BTC

# Топ-3 самых дорогих
show-rates --top 3

# Курсы относительно RUB
show-rates --base RUB
```

## Кэш и TTL

Курсы хранятся в `data/rates.json` с метаданными `updated_at` для каждой пары.

- **TTL** (время жизни кэша) задаётся в `config.json` ключом `RATES_TTL_SECONDS` (по умолчанию **300 секунд** = 5 минут).
- При запросе курса (`get-rate`, `show-portfolio`) система проверяет TTL. Если кэш истёк — автоматически перезагружает из файла.
- Для принудительного обновления выполните `update-rates`.

Если кэш пуст (первый запуск), команды `get-rate` и `show-portfolio` выведут:
```
Локальный кеш курсов пуст. Выполните 'update-rates', чтобы загрузить данные.
```

## API ключи

### ExchangeRate-API

Для работы ExchangeRate-API необходим бесплатный API ключ.

**Установка**:
1. Зарегистрируйтесь на [exchangerate-api.com](https://www.exchangerate-api.com/)
2. Получите API ключ в панели управления
3. Установите как переменную окружения:
   ```bash
   export EXCHANGERATE_API_KEY="ваш_ключ"
   ```

Без ключа клиент ExchangeRate-API пропустит инициализацию, но CoinGecko продолжит работать.

### CoinGecko

CoinGecko не требует API ключа для базового использования (есть лимиты на запросы).

# Управление пользователями

## Регистрация

**Команда** `register --username <str> --password <str>`

**Ограничения**:
- Имя пользователя:
    - Не пустое
    - Ранее не регистрировалось
- Пароль
    - Минимум 4 символа

**Пример**: `register --username user --password pass`

**Пример успешной регистрации**:
`Пользователь 'user' зарегистрирован (id=1). Войдите: login --username alice --password ****`

**Возможные ошибки**:
- Имя пользователя 'user' уже занято
- Пароль должен быть не короче 4 символов

---

## Вход

**Команда** `login --username <str> --password <str>`

**Ограничения**:
- Пользователь должен быть зарегистрирован
- Пароль должен совпадать

**Пример**: `login --username user --password pass`

**Пример успешного входа**:
`Вы вошли как 'user'`

**Возможные ошибки**:
- Пользователь 'user' не найден
- Неверный пароль

# Работа с портфелем

## Показать портфель

**Команда** `show-portfolio [--base <str>]`

**Ограничения**:
- Пользователь должен быть залогинен
- Код базовой валюты — 2–5 заглавных латинских букв (например, USD, EUR)
- У пользователя должен быть хотя бы один кошелёк

**Параметры**:
- `--base <str>` — валюта, в которой выводится итоговая стоимость (по умолчанию USD)

**Пример**: `show-portfolio --base USD`

**Пример вывода**:
```
Портфель пользователя 'user' (база: USD):
- USD: 100.0000 → 100.0000 USD
- EUR: 50.0000 → 53.9300 USD
---------------------------------
ИТОГО: 153.93 USD
```

**Возможные ошибки**:
- Сначала выполните login
- У пользователя 'user' нет кошельков
- Не удалось получить курс для EUR→USD
- Неизвестная базовая валюта 'ABC'

---

## Купить валюту

**Команда** `buy --currency <str> --amount <float>`

**Ограничения**:
- Пользователь должен быть залогинен
- Код валюты — 2–5 заглавных латинских букв
- Amount — положительное число

**Параметры**:
- `--currency <str>` — код покупаемой валюты
- `--amount <float>` — количество единиц валюты

**Пример**: `buy --currency EUR --amount 100`

**Пример успешной покупки**:
```
Покупка выполнена: 100.0 EUR по курсу 0.9271 USD/EUR
Изменения в портфеле:
- EUR: было 0.0 → стало 100.0
Оценочная стоимость покупки 92.71 USD
```

**Возможные ошибки**:
- Не удалось получить курс для EUR→USD
- Неизвестная валюта 'ABC'

---

## Продать валюту

**Команда** `sell --currency <str> --amount <float>`

**Ограничения**:
- Пользователь должен быть залогинен
- Код валюты — 2–5 заглавных латинских букв
- Amount — положительное число
- На кошельке должно быть достаточно средств

**Параметры**:
- `--currency <str>` — код продаваемой валюты
- `--amount <float>` — количество единиц валюты

**Пример**: `sell --currency EUR --amount 50`

**Пример успешной продажи**:
```
Продажа выполнена: 50.0 EUR по курсу 0.9271 USD/EUR
Изменения в портфеле:
- EUR: было 100.0 → стало 50.0
Оценочная выручка: 46.36 USD
```

**Возможные ошибки**:
- У вас нет кошелька 'EUR'. Добавьте валюту: она создаётся автоматически при первой покупке.
- Недостаточно средств: доступно 50.0 EUR, требуется 100.0 EUR
- Курс EUR→USD недоступен. Повторите попытку позже.
- Неизвестная валюта 'ABC'

---

## Получить курс

**Команда** `get-rate --from <str> --to <str>`

**Ограничения**:
- Коды валют — 2–5 заглавных латинских буквы

**Параметры**:
- `--from <str>` — исходная валюта
- `--to <str>` — целевая валюта

**Пример**: `get-rate --from EUR --to USD`

**Пример вывода**:
```
Курс EUR→USD: 1.0786 (обновлено 2026-10-09T11:55:00)
Обратный курс USD→EUR: 0.9271
```

**Возможные ошибки**:
- Курс EUR→USD недоступен. Повторите попытку позже.
- Неизвестная валюта 'ABC'

---

## Выход

**Команда** `exit`

Завершает работу программы.

# Настройки проекта

Конфигурация проекта хранится в файле `config.json` в корне проекта. Настройки загружаются через синглтон `SettingsLoader`, который читает файл один раз при первом обращении.

## Поддерживаемые ключи конфигурации

| Ключ | Описание | Значение по умолчанию |
|------|----------|----------------------|
| `DEFAULT_BASE_CURRENCY` | Базовая валюта для конвертации и отображения итоговой стоимости портфеля | `"USD"` |
| `DB_FOLDER` | Путь к директории с базами данных (users.json, portfolios.json) | `"data"` |
| `RATES_TTL_SECONDS` | Время жизни кэша курсов валют в секундах (после этого происходит обновление) | `300` |
| `LOGS_PATH` | Путь к файлу логов действий | `"logs/actions.log"` |
| `LOG_LEVEL` | Уровень логирования (`DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`) | `"INFO"` |

## Пример config.json

```json
{
    "DEFAULT_BASE_CURRENCY": "USD",
    "DB_FOLDER": "data",
    "RATES_TTL_SECONDS": 300,
    "LOGS_PATH": "logs/actions.log",
    "LOG_LEVEL": "INFO"
}
```

# Логирование

## logging_config.py

Модуль настраивает систему логирования с ротацией файлов.

### Особенности

- **Формат логов**:
  ```
  INFO 2025-10-09T12:05:22 BUY user='alice' currency='BTC' amount=0.0500 rate=59300.00 base='USD' result=OK
  ```
- **Ротация файлов**: по размеру (10 MB), до 5 бэкап-файлов
- **Уровень по умолчанию**: `INFO`
- **Для отладки**: установите `"LOG_LEVEL": "DEBUG"` в config.json — появится вывод в консоль.
  
  для level="INFO" записи попадают только в файл
- **Хранение**: логи действий по-умолчанию пишутся в `logs/actions.log`. 
  Можно изменить в `LOGS_PATH` параметре файла config.json.

## decorators.py

Декоратор `@log_action` предназначен для автоматического логирования операций register, login, buy, sell.

### Использование

```python
@log_action(action="BUY")
def buy(user_id: int, currency_code: str, amount: float): ...


@log_action(action="SELL", verbose=True)
def sell(user_id: int, currency_code: str, amount: float): ...
```

### Параметры декоратора

| Параметр | Описание |
|----------|----------|
| `action` | Название действия: `BUY`, `SELL`, `REGISTER`, `LOGIN` |
| `verbose` | Если `True`, добавляет состояние кошелька «было→стало» |

### Логируемые поля

| Поле | Описание |
|------|----------|
| `timestamp` | Время операции (ISO формат) |
| `action` | Название действия |
| `user_id` / `username` | Идентификатор или имя пользователя |
| `currency` | Код валюты |
| `amount` | Количество единиц |
| `rate` | Курс конвертации |
| `base` | Базовая валюта |
| `result` | `OK` или `ERROR` |
| `error_type` | Тип исключения (при ошибке) |
| `error_message` | Сообщение об ошибке (при ошибке) |

### Примеры записей

**Успешная покупка**:
```
INFO 2025-10-09T12:05:22 BUY user='alice' currency='BTC' amount=0.0500 rate=59300.00 base='USD' result=OK
```

**Ошибка**:
```
ERROR 2025-10-09T12:06:10 SELL user='alice' currency='EUR' amount=100.0000
 result=ERROR error_type=InsufficientFundsError 
 error_message='Недостаточно средств: доступно 50.0 EUR, требуется 100.0 EUR'
```
